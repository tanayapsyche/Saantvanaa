# Custom Fonts

## Ananda Namaste

To use the **Ananda Namaste** font by Ananda K. Maharjan (the font you requested):

1. Download the font files from one of:
   - https://www.fontmirror.com/ananda-namaste
   - https://www.wfonts.com/font/ananda-namaste
   - Or purchase from Creative Market: https://creativemarket.com/aannda

2. Place the font file(s) in this directory as `AnandaNamaste-Regular.ttf` (or .otf)

3. Open `src/app/layout.tsx` and uncomment the `localFont` block for Ananda Namaste. It will then automatically replace the current display font (Rozha One) throughout the site.

## Current Fallback

While Ananda Namaste isn't placed here, the site uses **Rozha One** (a Google Font inspired by early Hindi magazine headlines) for display headings — it has a similar decorative, South Asian feel.
